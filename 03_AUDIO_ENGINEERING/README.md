# 03 Audio Engineering

Good audio saves weak picture. Bad audio ruins strong picture.

| Folder | Read when you need to... |
|---|---|
| `dialogue-cleanup/` | Clean voice recordings, fix cuts in speech |
| `sound-design/` | Choose music, build a sound-effect palette |
| `mixing-and-mastering/` | Balance voice, music, effects; duck; EQ; limit |
| `loudness-and-export/` | Hit loudness targets and export correctly |

**Order of work:** clean dialogue → cut → music and effects → mix → master → measure the final file.

**Measure the file you deliver.** Not the project, not the WAV: the encoded file, in stereo.
