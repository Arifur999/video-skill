# Type systems and pairing for video

## Pick by tone

| Tone | Type direction |
|---|---|
| Calm | Light weights, generous spacing, small sizes |
| Trustworthy | Clear sans, numbers in monospace |
| Urgent | Condensed, tight, uppercase |
| Playful | Rounded, mixed sizes |
| Premium | Serif display or very clean sans, wide tracking |
| Technical | Monospace, tabular numbers |
| Warm / human | Humanist sans, a handwriting accent |
| Bold | Heavy weights, huge scale |

## One system per film (default)

- One main family, two weights at most.
- One accent family used rarely (5–20% of text) for emphasis or soft words.
- A monospace only where data or code appears.

## When to break the one-system rule

A fast, multi-section film can give each beat its own family so every section feels like a different world. This works only if each section still has one clear hierarchy and the colour palette holds the whole film together. Do it deliberately and keep a list of the families used.

## Video-specific rules

- Heavy weights survive compression and small screens. Hairline weights vanish on mobile and in dark scenes unless the size is large.
- Letter-spacing: slightly open for all-caps; slightly tight for large display sizes.
- Avoid pure white on pure black for long text. Slightly off-white reads softer.
- Never rely on a font being installed. Embed or load locally, and render a test frame on the machine that will do the final render.
- Keep a licence note for each font (open licences like OFL are safest for client work).

## Gradient and glow text (premium dark style)

A vertical white-to-grey gradient fill gives a metallic look. A soft glow behind emphasised words adds depth. Use on hero text only. If every block of text has both, the effect stops meaning anything.

## Hierarchy check

Squint at a frame. You should see, in order: the key word, the supporting line, the label. If two things compete, shrink or dim one.
