# 01 Motion Design

How things move, how text moves, how shots connect, and how to add texture without making a mess.

| Folder | Read when you need to... |
|---|---|
| `animation-principles/` | Pick easing and timing, choreograph several things, or set the overall motion philosophy of a piece |
| `typography-animation/` | Animate words, titles, headlines, kinetic type |
| `transitions-and-camera/` | Connect shots, move a virtual camera, avoid repeating yourself |
| `visual-effects/` | Add grain, glow, depth, glass, grids, and keep renders deterministic |

**Order of decisions:** tone first (`02_VIDEO_EDITING/storytelling-and-pacing/tone-matrix.md`), then pacing, then transitions, then easing, then effects. Effects come last. If the piece only works because of effects, the idea is weak.
