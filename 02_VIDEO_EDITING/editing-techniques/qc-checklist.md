# QC checklist

Copy this into the project notes for each delivery. A tool pass is not a review. **A human watch-through is the final gate.**

## Picture

- [ ] First 2.5 seconds checked frame by frame. Nothing covers the mouth or chin.
- [ ] First frame of every face shot checked.
- [ ] Frame strips (about 10 frames either side) at every cut. Catch one-frame empty panels and captions flashing on the wrong shot.
- [ ] No cropped faces, text overflow, or off-safe-area elements.
- [ ] Transitions all play and none flash black.
- [ ] Colour consistent across shots.
- [ ] End card or last frame holds long enough.

## Captions and text

- [ ] Contrast measured behind every caption (not guessed).
- [ ] Captions never over the mouth.
- [ ] Every word matches what is said.
- [ ] Spelling and brand names checked.
- [ ] Text stays within platform safe zones.

## Audio

- [ ] Every word whole at every cut. Transcribe the final render and compare with the raw. A transcript alone is not proof, because speech-to-text guesses a clipped word correctly while a listener hears it broken. Listen at each cut.
- [ ] Last spoken word not faded.
- [ ] Music ducks under speech; no sudden jumps.
- [ ] Sound effects tied to real actions, not every cut.
- [ ] Loudness and true peak measured **on the delivered file**, on stereo.
- [ ] No clipping, no hum, no pops at edits.

## Sync

- [ ] Lip sync holds from start to end (check the last 10 seconds specifically).
- [ ] Music hits and picture hits line up where planned.

## Technical

- [ ] Resolution, frame rate, aspect ratio, codec as specified.
- [ ] File plays on a phone and a laptop.
- [ ] Duration matches the brief.
- [ ] File name and version follow the project convention.

## Automated checks: use with care

AI "watch tests" (a video model reviewing the render) find candidate problems but are noisy and sometimes invent effects. Verify every complaint on real frames before acting. A panel of imagined viewers ("would they finish? where did they stop?") is more useful than a 1–10 score.

## Delivery gate

Do not call it done until: checklist complete, final file watched start to end, loudness measured on the final file.
