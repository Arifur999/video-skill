# 02 Video Editing

Cutting, story, colour, and on-screen text.

| Folder | Read when you need to... |
|---|---|
| `editing-techniques/` | Cut footage, handle speech, source B-roll, check a finished edit |
| `storytelling-and-pacing/` | Plan the story, choose tone, set rhythm, write a brief and storyboard |
| `color-grading/` | Correct, grade, and give a film a consistent look |
| `captions-and-titles/` | Style captions, time subtitles, build titles and lower thirds |

**Default order of work:** brief → story plan → rough cut → B-roll and graphics → captions → colour → sound → QC → deliver.

**The loop that makes quality compound:** every time you give a note on a draft, the fix goes into the file that governs that behaviour. See `05_RESEARCH_NOTES/lessons-learned/note-to-rule-loop.md`.
